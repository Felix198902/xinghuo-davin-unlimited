## 安装

### 方式一：从插件商店装（推荐）

打开 Devin / Windsurf 的扩展面板，搜索 **星火 Davin 无限**，点安装即可。

这样装以后**有新版本会自动提示更新**，不用再回来手动下载。

> **商店里显示的版本可能滞后。** 编辑器的插件商店有自己的缓存，新版本上架需要时间，有时会比较久。
> 搜不到最新版、或者装完发现还是旧版本，都属正常 —— 用下面的方式二即可马上用上。
> **版本以本页 [Releases](../../releases) 为准。**

### 方式二：下载安装包手动装

1. 到 [Releases](../../releases) 下载最新的 `.vsix` 文件。
2. 打开 Devin / Windsurf → 扩展面板 → 右上角 `⋯` → **Install from VSIX...**（从 VSIX 安装）。
3. 选中刚下载的 `.vsix`，装完按提示**重载窗口**。

也可以用命令行：

```bash
code --install-extension xinghuo-unlimited-token-1.9.3.vsix
```

（把 `code` 换成你实际用的命令：Windsurf 是 `windsurf`，Devin 是 `devin`。）

## 三步开始用

1. 打开左侧边栏的 **星火 Davin 无限** 面板 —— 没激活也能先看看：余额、模型库、全局无限模式、用量报表都在里面。
2. 粘贴**激活码**或**访问令牌**（`sk-` 开头），点「立即激活」。
   没有激活码？面板里点「**立即购买激活码**」直达下单页，下单即得。
3. 在**模型库**里勾选想用的模型 → 点「保存并应用」→ 按提示**重载一次窗口**。

回到对话，打开模型下拉框，顶部就是 **「请选择 Max 高级模型」** 分组，你勾的模型都在里面。

> 为什么要重载窗口？模型下拉框的内容是编辑器启动时缓存的，它自己不会再去取。
> 所以勾选**落盘和路由都是即时的**，但下拉框要重载才看得到变化。

| **模型库** | 在售模型按厂商分组罗列，勾哪些就置顶哪些。取消勾选会同时撤下路由。 |

## 常见问题

**装完在模型列表里没看到新模型？**
勾选保存后要**重载一次窗口**（面板里会出现橙色横幅，点上面的「重载窗口」）。

**切到 Devin Local 之后模型不见了？**
Cascade 和 Devin Local 都能用你勾选的模型。改完勾选重载一次窗口，两边就都更新了。

**余额显示的是旧数字？**
面板会如实标注「这是几分钟前的快照」。点刷新即可取最新。

**想彻底恢复官方直连？**
面板里点「退出激活」；万一卡住，命令面板搜「复原官方直连」。
